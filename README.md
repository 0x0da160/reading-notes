# 初読の赤入れリーダー

自作の日本語小説（Markdown・EPUB）を縦書きで読み、気づいた箇所にひと言を残して、読みかけの位置に戻るための個人用ツールです。原稿はブラウザーの中だけで扱い、どこにも送信しません。

アプリケーション仕様は [OKF v0.2 ナレッジ索引](./docs/knowledge/index.md) から参照できます。まず [目的・動作環境](./docs/knowledge/overview.md) を読み、実装・検証・運用の各文書へ進んでください。

## 開発

Node.js 22 を使います。

```sh
npm ci
npm run dev          # 開発サーバー（http://localhost:5173/reading-notes/）
npm test             # 本文モデル・解析の単体テスト（Vitest）
npm run build        # 本番ビルド（CSP の meta と Service Worker を含む）
npx playwright test  # E2E（Chromium・WebKit。先に build が必要）
```

`main` への push で GitHub Pages（`/reading-notes/`）に公開します。リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。

## 対応形式と上限

- Markdown（`.md`、`.markdown`、UTF-8）：見出し・段落・改行・リスト・強調。ルビは `｜親文字《よみ》` の形だけ。生HTMLは文字列のまま表示し、画像は代替テキストだけを表示します。
- EPUB 3（DRMなし・リフロー型）：読書順、目次、見出し、段落、ルビ、同梱の PNG・JPEG・静止WebP。原稿側のCSS・フォント・スクリプトは使いません。
- 上限は暫定値です（[§9.4](./docs/knowledge/verification.md#section-9-4)）：ファイル 50 MB、EPUB展開後 200 MB、画像1点 10 MB・4,000万画素。

## 操作

- 左端タップ・右スワイプ・「← 次へ」で次のページ、右端タップ・左スワイプ・「前へ →」で前のページ。キーボードでは ← / → も使えます。
- 文字を選択している間はページ送りをしません。
- 赤入れ：本文を長押しして範囲を選び、下に出る「赤入れ」を押します。種別（疑問・残したい・修正指定）を選び、ひと言を書いて「保存」（⌘／Ctrl+Enter でも保存）。Enter は改行だけで、保存しません。保存・取消のあとは選び始めたページに戻ります。
- ページまたぎ：始点を含む箇所を選んで「範囲を延ばす」を押し、専用の「← 次」「前 →」で移動して終点を含む箇所を選び「ここまで」。始点を変えるときは「取消」して選び直します。
- 一覧：本文順に並びます。項目を押すと本文で確認でき（読書位置は変わりません）、「一覧に戻る」で元のページと項目に戻ります。編集・削除もここから行います。本文のハイライトは一覧の下の切替で隠せます。

## 保存・バックアップ・復元

- 通常タブでは、原稿・読書位置・設定・赤入れをブラウザー（IndexedDB）に保存し、再読み込みで復元します。元の原稿ファイルは変更しません。ブラウザーの保存は次に開いたときまで残ることを保証しないため、作業を残すには JSON を書き出してください。
- 保存の状態は「一覧」の上部に出ます：「ブラウザー保存済み」／「このタブで作業中」（保存待ち・保存できなかった・別のタブで更新された・保存枠に書かない）。保存できなくても、このタブでは読む・赤入れ・書き出しを続けられます。
- 一覧 →「保存と書き出し」から：
  - **JSONを書き出す**：作業再開用。原稿本体は含みません。共有シート（またはダウンロード）から「ファイル」に保存し、保存できたことを確かめてから「ファイルへの保存を確認した」を押します。以後の変更は「未バックアップの変更」として示します。
  - **JSONから復元**：JSON を選び、書き出したときと同じ原稿ファイルを選びます（SHA-256 の版IDを照合）。既存の赤入れがあれば件数と版IDを示し、確認してから置き換えます。自動では合わせません。
  - **Markdownを書き出す**：AI に渡す検討用。全件または選んだ赤入れについて、引用とコメントを本文順に出します。AI への送信はしません。
- **元の原稿と JSON は同じフォルダーに一緒に保管してください。** JSON だけでは本文を復元できず、原稿を書き換えると版IDが変わって復元できなくなります。改稿したら、改稿前の原稿も JSON と一緒に残してください。
- 別の原稿を開くときは、失われる原稿・赤入れ・読書位置を示し、先に JSON を書き出せます。「このタブだけで開く」を選ぶと、保存枠を残したままこのタブだけで作業します。

## 位置未確定と再割り当て

本文から位置を確かめられない赤入れ（JSON の本文モデルが古い、引用と前後の文が一意に一致しないなど）は「位置未確定」として一覧の末尾に分け、本文には描きません。項目の「位置を指定」から、同じ引用の候補を本文で仮表示して選ぶか、「本文から選び直す」でページをまたいで指定し直せます。一件でも自動では確定しません。確定すると ID・種別・コメントを保ったまま範囲と引用を更新し、元の引用は JSON に残します。

## サンプル

`samples/anata-made-sankagetsu.epub` は作者の許諾を得て置いている検証用サンプル（『あなたまで三か月』）です。著作権は作者に帰属し、奥付の表示に従い、無断の複製・転載はできません。`samples/sample.md` はルビ・縦中横・見出し・生HTMLの扱いを確かめるための短い試験用原稿です。

私用の原稿・赤入れ・バックアップはこのリポジトリに置かないでください（[通信・オフライン・公開](./docs/knowledge/deployment.md#section-8)）。
