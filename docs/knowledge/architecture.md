## 2. 技術構成

| 領域 | 方針 |
|---|---|
| アプリ | React + TypeScript + Vite。初版では専用ルーターやサーバー機能を追加しない。 |
| UI・スタイル | ネイティブHTMLを基本とし、CSS ModulesとCSSカスタムプロパティで構成する。ボタン・入力欄・種別の選択はネイティブ要素を優先。 |
| 汎用ダイアログ | ネイティブの `<dialog>`（`showModal()`）を使う。削除・置換などの確認でフォーカスを閉じ込め、Escで閉じ、閉じると呼び出し元に戻す。UIコンポーネントライブラリは導入しない。 |
| 読書・赤入れ | 縦書き、本文の選択、ページまたぎ、入力パネル、再割り当ては専用実装。既製のスワイプ式Drawerをそのまま使わない。 |

- 本文表示・ページ計算と、コメントやパネルの状態を分離する。文字入力、キーボード開閉、テーマ変更、入力パネル表示だけでは再組版しない。
- 初版はコード分割しない。EPUB解析・書き出しを含む必須機能をすべて初期バンドルに入れ、実行時に追加取得するコード（動的 `import`、別ファイルのWorker、WASM等）を持たない。XHTMLの解析に使う `DOMParser` はWorkerで使えないため、初版はWorkerを使わず、長い解析・組版は細かく区切って実行し、入力への応答を妨げない。これにより、アプリが表示された時点で現在のタブは追加通信なしで全機能を実行できる（[§8](./deployment.md#section-8)）。
