## 2. 技術構成

| 領域 | 方針 |
|---|---|
| アプリ | React + TypeScript + Vite。初版では専用ルーターやサーバー機能を追加しない。 |
| UI・スタイル | ネイティブHTMLを基本とし、CSS ModulesとCSSカスタムプロパティで構成する。ボタン・入力欄・種別の選択はネイティブ要素を優先。 |
| 汎用ダイアログ | Base UIを必要な部品だけ採用。削除・置換などでフォーカスを管理し、閉じると呼び出し元に戻す。shadcn/uiは全面採用せず、設定・確認の一部に限り選択可。Tailwindは必須ではない。 |
| 読書・赤入れ | 縦書き、本文の選択、ページまたぎ、入力パネル、再割り当ては専用実装。既製のスワイプ式Drawerをそのまま使わない。 |

- 本文表示・ページ計算と、コメントやパネルの状態を分離する。文字入力、キーボード開閉、テーマ変更、入力パネル表示だけでは再組版しない。
- EPUB解析は別チャンクとする。通常タブの再起動に必要なキャッシュと、キャッシュに依存しない現在のタブの起動準備の両方に含める。書き出しなど他の必須機能の遅延チャンクも同様に扱う（[§8](./deployment.md#section-8)）。初回原稿表示・ページ送り・入力応答は別々に実機で測り、代表原稿で結果を記録する。
