# 赤入れ操作

<a name="section-5"></a>

## 5. 赤入れの操作

<a name="section-5-1"></a>

### 5.1 単ページと共通動作

1. Safari標準の長押しと選択ハンドルで、同一ページの複数行・段落を選べる。選択確定前の長押し、ハンドル移動、範囲指定・コメント入力中、入力を閉じる操作では通常のページ送りを発火させない。
2. 「赤入れ」で範囲と引用を確保してから入力を開く。仮ハイライトと引用プレビューを出す。種別は「疑問」（既定）、「残したい」、「修正指定」。短いコメントで保存でき、通常保存に追加確認を要求しない。
3. 保存すると確定ハイライトを表示する。保存・取消後は操作開始時に記録した本文アンカーへ戻す。取消は仮表示だけを消し、重複範囲の削除は該当IDのハイライトだけに作用する。
4. 一覧から対象へ移動し、確認・編集・削除できる。この移動は一時プレビューで、通常の読書再開位置を更新しない。閉じると元の本文アンカーと一覧の選択項目に復帰する。位置未確定の項目は本文で表示せず、一覧で確認・編集・削除・書き出し・再割り当てを可能にする。

<a name="section-5-2"></a>

### 5.2 ページまたぎ

1. 最初のページで範囲の起点を含む箇所を長押し選択し、「範囲を延ばす」を押す。押下時に選択の論理先頭を固定し、Safariの選択状態から切り離す。
2. 「終点を選択中」と表示し、専用の前後ボタンでページを移動する。終点を含む箇所を長押し選択し「ここまで」を押すと、終点側の選択末尾までを一件の範囲として確定する。終点が始点以前なら確定しない。途中のページ、連続した章・セクション、EPUBの本文ファイル境界を越えて指定できる。通常ジェスチャーはこの間無効とする。
3. 確定前は終点を選び直せる。始点を変える場合はキャンセルして取り直す。入力欄は「ここまで」で範囲を確定してから開く。確定後に引用の冒頭と末尾を確認でき、長い引用は展開して全体を読める。出力では同じID・引用を持つ一件とし、章またぎなら開始章〜終了章を表示する。
4. 保存・取消後は、最初に選んだページの本文アンカーへ戻す。ページごとには保存せず、組版が変わっても同じ論理範囲を使い、表示中の各ページとの交差部分だけを描く。単ページ・ページまたぎとも、途中で回転しても保存・取消後は開始時のアンカーを含む再組版後のページへ戻る。
