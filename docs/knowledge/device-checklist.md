# iPhone実機チェックリスト

[仕様ナレッジ索引](./index.md) · [検証と合格条件](./verification.md#section-9-3)

[§9.3](./verification.md#section-9-3)の確認を、依頼者がiPhone 17のSafariで行うための手順と記録欄。結果欄が空欄・「未実施」の項目は不合格扱いで、自動テストの結果では代用しない（[§1](./overview.md#section-1)）。記録したら `log.md` に日付と対象版を残す。

<a name="setup"></a>

## 準備

- 対象：GitHub Pagesの `https://<ユーザー名>.github.io/reading-notes/`。確認した版は、アプリの「保存と書き出し」を開いたときのURLとGitHubのコミットで記録する。
- 試料：`samples/anata-made-sankagetsu.epub`（EPUB）と `samples/sample.md`（Markdown）を「ファイル」に置く。オフライン確認の前に、オンラインではEPUBを一度も開かないこと。
- 記録する環境：端末・iOS/Safariのバージョン・試料サイズ・通常タブ／プライベートの別。
