## 9. 検証と合格条件

<a name="section-9-1"></a>

### 9.1 最初の実機試作

両形式への展開や設定画面の作り込みに先立ち、iPhoneの代表的な日本語原稿1章で「縦組み → ページ送り → ページ末尾を長押し → 次ページまで延長 → 日本語入力 → 保存／取消 → 元の本文位置へ復帰」を通す。単ページ選択、本文端での誤ページ送り、変換中の誤保存も確認する。早期に、通常タブの再読み込み復元と、プライベートで通信を切断してから初めてEPUBを開く操作を小さな公開可能サンプルで通す。

代表的な長編・挿絵入り原稿で、端末・iOS/Safariバージョン・試料サイズ・計測条件と結果を記録する。試作完了時に、入力ファイルサイズ、EPUB展開後の累計サイズ、画像1点あたりのサイズ・画素数の上限、および初回表示・再組版・ページ送り・入力応答の許容時間を実装者と依頼者で確定し、検証ナレッジに記載する。ページ送りは操作から表示安定まで、入力応答は入力から画面反映までを別々に測る。選択やり直し回数の許容上限も同じ時点で決める。未決定または未計測のまま初版を合格にしない。

<a name="section-9-2"></a>

### 9.2 実装者：自動テスト（Chromium・WebKit）

- PlaywrightでChromiumとWebKitの両方に同じ試験を流す。WebKitの結果もiPhone実機の代用にはしない。
- 両形式の縦組み、左右の進み方、全ページの論理本文の欠落・重複がないこと。回転相当・文字サイズ変更後に本文位置とハイライトが合うこと。
- 単ページ、隣接2ページ、途中ページを含む連続範囲、章・EPUB本文ファイルまたぎを一件として保存・描画・出力・復元。保存・取消・重複範囲の片方の削除を確認する。
- 重複引用、章またぎの片端不明、旧本文モデルで誤付与が起きないこと。候補0・1・複数、候補選択、手動のページまたぎ再指定、引用変更、取消、確定後のJSON往復、ID・コメント・種別・初回引用・読書位置の保持を確認する。
- 別原稿版、不正JSON、未対応スキーマ、再取込、原稿切替取消、読込エラー、新規ブラウザーコンテキスト、書込失敗、別タブ競合を試す。失敗後も現在のデータを守り、必要な場合は書き出せること。置換処理の失敗時に旧枠と未保存メモリ作業が残ること、世代12の書き出し確認で世代13がバックアップ済みにならないことも確認する。
- CSPを入れた本番ビルドで違反がゼロ。原稿由来の外部・同一オリジン通信がゼロ。EPUB目次の内部移動は通信なしで成功すること。オフライン通常再起動と、Service Workerに依存しない現在のタブでの継続（実行時の追加取得がゼロであること）を、いずれもオンラインでEPUBを一度も開かず、遮断後に初回EPUBを開く手順で確認する。旧版で保存→アプリ更新→オフライン復元も確認する。
- 幅320 CSS px相当とデスクトップで、長いファイル名・URL・挿絵がはみ出さない。Tab・Shift+Tab・Escとダイアログのフォーカス復帰、明暗での可読性・フォーカス表示・色に頼らない種別表示を確認する。[§6.3](./position-model.md#section-6-3)の正解例、`rp`・`hidden` 要素の除外、`spine` に含まれるナビゲーション文書と本文中リンク、縦中横と段落字下げの表示、上限超過、AI用Markdownの原稿名・章名・コメント等が見出しやフェンスを含む場合も検証する。

<a name="section-9-3"></a>

### 9.3 依頼者：iPhone 17 Safari実機

通常タブとプライベートブラウズの両方で次を確認する。

1. 「ファイル」から両形式を開き、端タップ・スワイプ・ボタンで指定方向に進む。本文・挿絵に見切れ・重なり・欠落・重複がない。
2. 長押しで複数行、ページ境界、章境界を注釈する。キーボードや変換候補が出ても引用・仮表示・保存／取消を維持する。端末回転、Safariのアドレスバーの変化、キーボードの再開閉で、誤操作・意図しない拡大や横ずれ・入力消失がない。ピンチズームは使える。
3. 保存・取消から元の読書位置に戻り、前後移動・回転・文字サイズ変更後も対象が合う。明暗、重複、非表示切替を確認する。
4. 一覧で曖昧な候補を見比べ、候補なしの項目は手動でページまたぎ再指定する。取消で変化せず、確定は指定範囲だけに適用され、読書再開位置を変えない。
5. MarkdownとJSONを「ファイル」に置き、ファイルの実在を確認する。別セッションで同じ原稿とJSONから復元する。JSONからの復元は次のブラウザー保存の確認とは別に行う。
6. 通常タブのみ：原稿・設定・位置・赤入れを保存し、「ブラウザー保存済み」の後にページを再読み込みする。元ファイルやJSONを再選択せず、すべて復元することを確認する。
7. オフライン検証：オンラインではEPUBを一度も開かずに準備する。通常タブでは「オフラインで開き直せる」の後に機内モードで開き直す。プライベートではアプリの表示後に通信を切り、タブは閉じない。それぞれ遮断後に初めてEPUBを開き、両形式の読込・読書・赤入れ・再割り当て・書き出しを行う。通常タブでの旧版からの更新後の復元も実機で確認する。

通し試読は15分・赤入れ10件を目安に、選択のやり直し、本文を探し直した回数、誤ページ送り、誤付与、コメント消失を記録する。誤ページ送り・誤付与・コメント消失・保存または取消直後に本文を探し直した回数は、各0件を合格条件とする。選択のやり直しは[§9.1](#section-9-1)で定めた回数以下とする。[§1](./overview.md#section-1)・[§9](#section-9)で必須の項目に不合格・実機未確認が残る場合、初版はリリースしない。自動テストの合格で代用しない。
